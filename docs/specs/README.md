# Specs

Design documents for the Krewire Framework. Written before implementation for anything non-trivial.

## Index

See [`index.md`](./index.md) for the full specification list (33 specs, ordered by impact-to-effort then dependency chain).

## Naming

File name: `{ProjectId}-{Scope}-{SpecID}-{slug}.md`. One spec per initiative.
`{ProjectId}` is `KWF` here, `{Scope}` a short category (`ARCH`, `CLI`, `WEB`, `SSG`, `UI`, `APP`, `INFRA`, `SVC`, `WASM`, ...), `{SpecID}` a unique random 5-character alphanumeric code, `{slug}` a kebab-case title.

See the root `AGENTS.md` for the full convention.
